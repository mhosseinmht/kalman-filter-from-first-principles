# Kalman Filtering from First Principles

A robotics-oriented tutorial series covering the mathematics, intuition, and implementation of Kalman filtering. I also try to explain concepts that are often skipped or treated as trivial, even though many learners may not yet be familiar with them or may have forgotten them. Without these foundations, understanding the logic behind Kalman filters can quickly become frustrating.

The goal is to build the concepts progressively, starting from uncertainty and covariance and eventually moving toward Kalman filtering and nonlinear state estimation.

## Contents

2. Gaussian Distributions
3. State-Space Models
4. Kalman Filter Prediction
